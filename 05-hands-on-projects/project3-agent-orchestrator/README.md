# Project 3: Dual-System Agent Orchestrator

An autonomous AI agent pipeline implementing Daniel Kahneman's Dual-Process cognitive architecture:
- **System 1 (Jev):** High-speed (sub-100ms) decision engine for intent classification, instant response caching, deterministic tool dispatching, and confidence scoring.
- **System 2 (Frontier LLM):** Deliberative reasoning engine invoked only when System 1 identifies high complexity or low confidence.
